# BOK워치

**유형** DATA · **분야** 경제 · **상태** PUBLIC  
**서비스** https://bokwatch.pages.dev/

---

## 한 줄 소개

다음 금통위 금리 결정을 시장 데이터로 추정하는 서비스. KOFR 선물 기반 모형 확률·총재 발언·기관 전망을 한 화면에서 봅니다. 매일 오전 10시 자동 갱신.

---

## 왜 만들었는가

금리 전망은 언론이 "전문가들은 동결 예상"이라고 전하지만, 시장이 실제로 어느 정도 확률로 금리 변화를 기대하는지는 KOFR 선물 가격을 직접 계산하지 않으면 알 수 없다. 이를 모형으로 전환해 동결·인하·인상 확률을 숫자로 제시하고, 총재 발언·의사록·기관 전망을 같은 화면에서 비교할 수 있도록 만들었다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 금리 결정 확률 추정 | KOFR 선물 기반 모형으로 다음 금통위 동결·인하·인상 확률 추정 |
| 회의별 기대 금리 전망 | 예정된 금통위별 시장 기대 기준금리 수준 표 |
| 확률 변화 히스토리 | 동결 확률 날짜별 추이 그래프 |
| 통방문 문구 비교 | 회의별 결정문 변화를 이전 회의와 나란히 비교 |
| 총재 발언·의사록 | 발언 발췌·의사록 요약·소수의견·점도표 |
| 기관 전망 컨센서스 | 증권사·IB 주요 기관 전망 모음 |
| 주요 경제지표 일정 | FOMC·CPI·고용 등 캘린더 |
| AI 참고 지표 | 뉴스 기사 분석 기반 통화정책 압력 신호 |

---

## 데이터 출처

- **ECOS (한국은행)** — 기준금리(722Y001), CD 91일 금리(817Y002)
- **KRX Open API** — KOFR 3개월 선물 정산가격
- **한국은행 공식 사이트** — 통방문 원문, 의사록, 점도표
- **연합뉴스 RSS** — 총재 관련 기사 자동 수집
- **data/reports.yaml** — 기관 전망·발언 수기 입력
- **OpenAI API** — 뉴스 분류·태깅 (AI 참고 지표용)

> 모형 확률은 추정값으로 시장의 확정적 전망이 아닙니다. 모형 가정과 한계는 서비스 내 공개.
