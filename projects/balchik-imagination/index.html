발칙한 상상

한국과 일본이 하나의 나라가 된다면?

두 나라를 더하는 일과, 하나가 되는 일 사이. 한일 공동체 구상을 숫자로 더해 보고, 생활 속 차이와 국민정서, EU의 경험을 따져 본 뒤 직접 공동체의 규칙을 설계해 보는 인터랙티브 사고실험입니다.

01 / WHY

왜 만들었는가

한일 공동체라는 구상은 정치인은 안보를, 기업인은 시장을 말하며 가끔 다시 나온다. 서비스는 이시바 시게루 전 일본 총리와 최태원 SK·대한상의 회장의 발언을 출발점으로 삼는다.

그런데 두 나라의 규모를 더하는 일과 하나의 나라가 되는 일은 전혀 다른 문제다. 숫자는 더해지지만 역사와 주권은 그렇게 더해지지 않는다. 이 간극을 데이터로 직접 만져 보도록 만든 것이 이 사고실험이다.

서비스는 "발칙한 것은 질문, 숫자는 엄격하게"라는 원칙을 내세웁니다. 본문의 전망은 자료와 제도에 근거한 편집 분석이며 실현 확률이나 도입 시점의 예측이 아닙니다.

02 / FEATURES

무엇을 할 수 있는가

합쳐 보면 세계 몇 위

명목 GDP, 인구, 군사비, 제조업 부가가치를 단순 합산해 세계 순위를 비교합니다. 국가별 순위와 기준연도도 직접 확인합니다.

생활 속 한일 차이

최저임금 한 시간, 같은 자동차 한 대, 서울과 도쿄의 84㎡ 집, 지하철 기본요금을 같은 원화 기준으로 비교합니다.

새 돈 1단위는 몇 달러

원화와 엔화의 비중과 단위를 직접 정해 가상의 새 통화가 몇 달러인지 계산합니다. 시장환율 전망이 아닌 가상 환산입니다.

국민정서의 13년

서로에 대한 호감도와 경제공동체 찬반 여론을 연도별 그래프로 봅니다.

EU의 경험

1950년 쉬망 선언부터 브렉시트까지 EU가 어디까지 하나가 됐는지 타임라인으로 보고, 한일에 주는 시사점을 살핍니다.

공동체 설계실

통합 수준, 공동의회, 공동통화 같은 결정의 규칙을 직접 선택해 나만의 공동체를 설계합니다.

03 / DATA & METHODS

데이터와 분석 방법

규모 비교
명목 GDP는 IMF(2024), 인구는 UN 중위 전망(2024), 군사비는 SIPRI(2025), 제조업 부가가치는 World Bank·BEA(2024). 합계는 단순 합산이며 지표별 기준연도가 다릅니다.
생활 비교
2026 적용 최저임금, 차량 표시가, 서울·도쿄 주택 가격, 지하철 요금 등. 원화 환산은 ECB 2026-10-30 기준 환율을 쓰며 환전 수수료는 포함하지 않습니다.
국민정서
EAI·IHJ 조사. 2025년 협력기관과 조사체계가 바뀌어 장기 변화에는 방식 변화의 영향이 섞일 수 있습니다.

서비스는 데이터 확인일 2026-10-31, 사전 수집된 정적 데이터를 쓰며 방문자의 LLM 호출이 없다고 밝힙니다. 출처, 계산 방법, JSON 다운로드는 서비스의 데이터·방법론 항목에서 확인할 수 있습니다. 군사비 순위는 실제 방위력과 같지 않고, 주택·자동차 비교는 같은 상품 비교가 아닐 수 있습니다.
