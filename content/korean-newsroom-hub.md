## 한 줄 소개

경제·금융·산업을 취재하는 기자가 ChatGPT에 숫자를 물을 때 한국은행 ECOS, 통계청 KOSIS, 금융감독원 OpenDART의 공식 API를 직접 조회하게 해 주는 MCP 도구. 답은 수치·단위·기준시점·출처와 함께 돌아옵니다. HUB는 이 도구를 소개하고 연결을 돕는 기자용 안내 사이트입니다.

> KOREAN NEWSROOM HUB는 기관 공식 서비스와 독립된 안내 사이트입니다.

---

## 왜 만들었는가

ChatGPT에 삼성전자 매출을 물으면 그럴듯한 숫자가 나옵니다. 기자가 불안한 것은 숫자가 아니라 기준입니다. 연결인지 별도인지, 연간인지 누적인지, %인지 %p인지, 어느 시점의 값인지. 기준이 하나만 어긋나도 기사의 숫자는 틀립니다. 이 도구는 그 확인을 공식 API 조회와 계산·검증 절차에 맡겨, 기자가 데스크에 넘길 출처와 계산 근거를 한 번에 받도록 합니다.

읽기 전용이며 기사를 자동으로 쓰지 않습니다. 원문 대조와 최종 판단은 기자의 몫입니다.

## 숫자로 보는 도구 (2026-11-10 화면 기준)

- 3개 기관 공식 API: 한국은행 ECOS, KOSIS, OpenDART
- 12개 도구: 검색, 비교, 검증
- 읽기 전용, 기사 자동 작성 없음
- 자동 테스트 73개, Docker·CI 검증 완료
- ECOS·KOSIS·DART 실제 ChatGPT 조회 확인 (운영자 시험 계정, 2026-11-10)
- 미지원: 기사 자동 작성, 상장 제조업 전체 순위, 관세청 HS 수출기여도, 은행 연체율 전수순위

### 질문과 답변 예시 (공식 과거 수치로 구성, 실제 응답 아님)

1. **금리 변화 검증**: 2025년 12월 저축성수신금리가 전월보다 0.09%p 올랐는지. 2025년 11월 2.81%에서 12월 2.90%로 0.09%p 상승 (한국은행 ECOS 121Y002).
2. **지역 고용률 비교**: 2025년 하반기 서울 중구와 부산 중구의 고용률 차이. 서울 58.4%, 부산 58.2%로 서울이 0.2%p 높음 (KOSIS, 전체 15세 이상 기준).
3. **연결 재무 확인**: 삼성전자 2024년 연간 연결 매출. 300,870,903,000,000원, 약 300.87조원 (OpenDART, 2024 회계연도 연간 연결, 별도 재무와 다른 값).

각 예시에는 기관, 기준시점, 자료 식별자, 표시 단위, 공표일, 기자가 확인할 점이 표시되고 후속 취재 질문을 복사할 수 있습니다.

## 연결 방법

1. ChatGPT 웹 계정과 MCP 연결 권한이 필요합니다. 개인 ECOS·KOSIS·DART 키는 필요 없습니다.
2. 사용자 지정 MCP 서버를 추가하고 이름과 서버 주소(HTTPS /mcp)를 넣은 뒤 인증 방식은 OAuth를 선택합니다.
3. 로그인 화면에서 처음이면 가입하고, 운영자가 접근을 승인하면 설정의 플러그인에서 도구를 새로 고칩니다.
4. 새 대화에서 플러그인을 선택하고 예시 질문을 붙여 넣습니다.

무료 HTTPS 서버는 미사용 시 잠들어 첫 접속이 느릴 수 있습니다. 로그인했는데 도구가 없으면 운영자 접근 승인을 확인하세요. 토큰·인증 코드·비공개 취재자료는 운영자에게도 보내지 마세요.

## 한계와 현재 상태

현재는 운영자가 승인한 계정만 이용하는 시험 운영 단계(MCP 0.4.0 RC)이며 일반 이용자 연결은 준비 중입니다. 항상 더 정확한 답을 보장하지 않으며 원문 대조와 기자의 판단이 필요합니다. 공식 사이트와 숫자가 다르면 사용을 보류하고 통계표 ID나 공시 접수번호로 확인합니다. API 단위 충돌은 공식 자료로 대조한 항목에 한해서만 보정합니다.
