# dataBREW — 26 editorial illustrations

26 individual pastel, print-style illustrations created for the dataBREW card thumbnails. Distinct graphics illustrate each service without repeating its full name. Restrained 2D vector shapes, a small amount of newsprint texture and limited spot colors replace the previous glossy 3D visuals.

- Published assets: `thumbs/editorial/*.webp` (880 × 396 px).
- Editable masters: `thumbs/editorial/source/*.svg`.
- Old thumbnails remain untouched and can be restored.
- HTML cards retain existing links, categories, ordering and descriptions in Korean and English.
