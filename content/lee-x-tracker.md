# 이재명 X 트래커

**유형** INTELLIGENCE · **분야** 정치 · **상태** PUBLIC  
**서비스** https://lee-x-tracker.raspos.chatgpt.site/

---

## 한 줄 소개

이재명 대통령이 X(구 트위터)에 게시한 1,065건의 게시물을 AI로 주제 분류·감정 분석하고 시계열·지지율과 함께 탐색하는 발언 아카이브.

---

## 왜 만들었는가

대통령의 X 게시물은 실시간 발언의 1차 소스지만, 과거 게시물을 체계적으로 분석하기 어렵다. AI 분류로 주제별로 정리하고, 시계열 변화와 감정 톤을 볼 수 있도록 만들었다.

---

## 데이터

- **X API v2** — 공식 계정 게시물 (본문·날짜·좋아요·리트윗·링크)
- **OpenAI API (GPT-4)** — 주제 분류 (경제·외교·복지·정치·기타) + 감정 분석
- **여론조사 데이터** — 게시 패턴 비교용 주간 지지율

> AI 분류 결과는 자동 분류이며 오류가 있을 수 있습니다. 분류 기준과 프롬프트를 서비스 내에서 공개합니다.

---

## 주요 기능

- 1,065건 전수 탐색 (날짜·주제·키워드 필터)
- 주제별 AI 분류 결과·근거 확인
- 일별·주별·월별 게시 빈도 차트
- AI 감정 분석 분포 (긍정·부정·중립)
- 지지율 비교 연동
- X 원문 직접 링크
