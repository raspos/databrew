손흥민 골 기념관

302골을 한 골씩, 출처와 함께 기록하다

함부르크에서 레버쿠젠, 토트넘과 LAFC, 그리고 대한민국 A대표팀. 프로 1군 공식 경기와 A매치에서 기록한 302골을 한 골씩 날짜·상대·득점 방식·출처와 함께 아카이브한 디지털 기념관입니다.

손흥민 골 기념관 메인 화면 — 통산 302골, A매치 59골 (2026-10-15 기준). 2026-10-23 캡처.

01 / WHY

왜 만들었는가

스포츠 보도에서 선수의 득점 기록은 통산 숫자로만 언급되는 경우가 많다. 각 골이 어떤 경기에서, 어떤 방식으로, 어떤 순간에 나왔는지 찾아볼 수 있는 곳이 없었다.

특히 손흥민처럼 다국적 무대에서 장기간 활약한 선수는 기록이 흩어져 있어 전수 확인이 어렵다. Transfermarkt와 ESPN 두 출처를 교차 검증해 골 단위로 확인할 수 있도록 정리하고, 개별 골의 유튜브 영상 링크까지 연결해 기록과 장면을 함께 볼 수 있도록 만들었다.

포함 범위: 프로 1군 공식 경기(분데스리가·FA컵·UCL·PL·MLS 등)와 A대표팀 A매치 본선·예선. 연령별 대표, 올림픽, 친선 경기, 승부차기는 제외합니다.

02 / FEATURES

무엇을 할 수 있는가

통산 302골 전수 탐색

팀별·대회별·시즌별·상대별·득점 방식·검증 수준 필터로 원하는 골을 찾아봅니다.

시즌별 득점 추이

연도별·클럽 시즌별 막대 그래프로 팀별 득점 분포와 커리어 흐름을 확인합니다.

득점 패턴 분석

발·머리 구분, 득점 시간대(15분 구간), 득점 방식(오픈플레이·PK·프리킥), 홈·원정, 경기 결과별 분포를 확인합니다.

슈팅 위치와 xG

Understat 데이터를 연결한 PL 및 분데스리가 득점의 슈팅 위치를 피치 위에서 확인하고 xG 분포를 봅니다.

개별 골 상세 패널

골 번호를 누르면 날짜·상대·스코어·득점 방식·도움·xG·영상 출처가 담긴 상세 패널이 열립니다.

유튜브 골 영상 연결

공식 채널 하이라이트 및 골 장면 클립이 확보된 골은 영상 링크를 직접 확인할 수 있습니다.

03 / DATA & METHODS

데이터와 분석 방법

Transfermarkt
골별 원자료: 날짜·대회·상대·득점 시간·스코어·골 유형·도움 제공. 유소년 포함 329행에서 공식 경기만 추출. 1차 확인 출처.
ESPN
경기별 득점 이벤트로 교차 확인. 275골에 ESPN 경기 링크 연결. 득점자·경기·시간(±1분) 일치 기준.
Understat
PL 2015/16–2024/25 및 분데스리가 2014/15 득점 138골의 슈팅 위치·xG·상황. 105×68m 규격으로 좌표 환산.
구단·연맹 공식
토트넘 구단(173골), PL 공식(127골, 발·머리), 분데스리가 공식, LAFC 구단, 연합뉴스 A매치 기록으로 합계 검증.
YouTube (공식 채널)
구단·리그·연맹·중계권사 공식 채널 영상만 연결. 비공식 채널은 포함하지 않습니다.

검증 수준 3단계: ① 골 단위(Transfermarkt·ESPN이 경기·득점자·시간 ±1분 일치) ② 경기 단위(두 번째 출처가 경기와 득점은 확인) ③ 단일 출처(Transfermarkt만 확인). 데이터 기준일: 2026-10-15.

04 / HOW TO USE

어떻게 활용할 수 있는가

스포츠 기자·콘텐츠 제작자

손흥민 관련 기사나 콘텐츠 제작 시 특정 상대·대회·시즌 기록을 빠르게 확인하고 출처 링크를 확보합니다.

축구 팬

기억에 남는 골의 상세 기록을 찾아보고 유튜브 영상으로 다시 확인하거나, 커리어 전체 추이를 탐색합니다.

스포츠 데이터 연구자

다국적 무대에 걸친 장기 커리어 데이터를 출처와 검증 수준과 함께 열람하고 분석 기반 자료로 활용합니다.

06 / TECH STACK

기술 및 제작 방식

빌드 결과물은 단일 HTML 파일(+ 데이터 JSON)로 구성된 정적 사이트입니다. 별도 서버 없이 브라우저에서 바로 동작하며 Claude.ai Artifact로 배포됩니다. 데이터는 goals.js / goals.json에 포함되며 Python 검증 스크립트로 무결성을 확인합니다.

07 / STATUS

개발 현황
