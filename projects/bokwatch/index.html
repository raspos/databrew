01 / WHY

왜 만들었는가

금리 전망은 언론이 "전문가들은 동결 예상"이라고 전하지만, 정작 시장이 실제로 어느 정도 확률로 금리 변화를 기대하는지는 별도의 계산 없이 알 수 없었다. 금융시장에서는 KOFR 선물 가격에 그 집단 판단이 이미 녹아 있다.

이를 모형으로 전환해 동결·인하·인상 확률을 숫자로 제시하고, 총재 발언·의사록·기관 전망을 같은 화면에서 비교할 수 있도록 만들었다. 단순한 전문가 의견 모음이 아닌, 데이터 기반의 확률로 통화정책을 읽는 도구를 목표로 한다.

모형 확률은 KOFR 선물 가격을 역산한 추정값으로, 시장의 확정적 전망이 아닙니다. 모형의 가정과 한계는 서비스 안에서 함께 공개합니다.

02 / FEATURES

무엇을 할 수 있는가

금리 결정 확률 추정

다음 금통위 회의의 동결·인하·인상 확률을 KOFR 선물 기반 모형으로 추정해 게이지로 표시합니다.

회의별 기대 금리 전망

앞으로 예정된 금통위 회의별로 시장이 기대하는 기준금리 수준을 표로 봅니다.

확률 변화 히스토리

동결 확률이 어떻게 변해 왔는지 날짜별 추이를 그래프로 확인합니다.

통방문 문구 비교

회의별 통화정책방향 결정문(통방문)의 문구 변화를 이전 회의와 나란히 비교합니다. 매파·비둘기 보조점수도 표시합니다.

총재 발언 및 의사록

한국은행 총재 공개 발언과 의사록 요약을 확인하고, 소수의견과 점도표를 함께 봅니다.

기관 전망 컨센서스

증권사·IB 등 주요 기관의 금리 전망을 모아 컨센서스로 정리합니다.

주요 경제지표 일정

미국 FOMC, CPI, 고용 일정과 한국 주요 지표 발표 일정을 캘린더로 봅니다.

AI 종합 판단 참고 지표

네이버 뉴스 기사에서 AI가 추출한 통화정책 압력 신호를 참고 지표로 제공합니다.

03 / DATA & METHODS

데이터와 분석 방법

ECOS (한국은행)
기준금리(722Y001) 및 CD 91일 시장금리(817Y002) 자동 수집. 금리 모형의 핵심 입력 데이터.
KRX Open API
KOFR 3개월 선물 정산가격 수집. KOFR 선물 → 회의별 동결·인하·인상 확률 역산에 사용.
한국은행 공식 사이트
통화정책방향 결정문 원문, 의사록 목록, 점도표 수집. 문구 변화 분석의 기반.
연합뉴스 RSS
총재 관련 기사 자동 수집·필터링.
수기 입력 (data/reports.yaml)
기관 전망, 총재 발언 발췌, 주요 경제 일정을 YAML로 직접 입력·관리.
OpenAI API
네이버 뉴스 기사 분류·태깅, 통화정책 압력지수 생성. AI 참고 지표로만 활용.

갱신 주기: 매일 오전 10시 GitHub Actions 자동 실행. 기관 전망·발언 항목은 수동 입력 후 배포.

04 / HOW TO USE

어떻게 활용할 수 있는가

경제·금융 기자

금통위 보도 전 시장 기대 확률과 전문가 컨센서스를 한 화면에서 확인해 기사 배경으로 활용합니다.

금융·투자 업무 종사자

동결 확률 변화 추이와 의사록 소수의견을 함께 보며 통화정책 방향 변화 신호를 모니터링합니다.

경제학·금융 연구자

KOFR 선물 기반 확률 모형의 방법론과 백테스트 결과를 직접 확인하고 참고 자료로 활용합니다.
