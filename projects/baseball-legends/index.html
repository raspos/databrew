추강대엽+김 메인 화면 — 5인 선수 카드와 시즌별 타율·홈런·세이브 비교 차트. 2026-10-15 캡처.

01 / WHY

왜 만들었는가

한국 야구 팬이라면 추신수·이대호·오승환의 이름은 알지만 커리어 전체를 한눈에 비교할 수 있는 곳은 없었다. KBO와 MLB에 걸친 기록이 흩어져 있어 단순 비교조차 쉽지 않다.

5인의 시즌별 전 기록을 KBO·MLB·NPB·MLB 마이너로 구분해 통합하고, 인터랙티브 차트로 커리어 흐름을 한 화면에서 비교할 수 있도록 만들었다. 추신수의 MLB 2,185안타와 오승환의 KBO+MLB 통산 세이브를 같은 척도로 볼 수 있는 도구다.

수록 선수: 추신수(외야수·타자), 강민호(포수·타자), 이대호(1루수·타자), 오승환(마무리·투수), 김현수(외야수·타자). KBO 공식 기록 + MLB Baseball Reference 기준.

02 / FEATURES

무엇을 할 수 있는가

5인 통산 기록 탐색

타율·홈런·안타·출루율·OPS(타자), 평균자책점·세이브·WHIP(투수) 기준으로 시즌별 기록을 확인합니다.

KBO·MLB 리그별 분리

KBO·MLB·NPB 리그별 기록을 분리해 보거나 통합해서 비교합니다.

커리어 타임라인

5인의 나이별 주요 스탯 변화를 겹쳐 보며 전성기와 커리어 흐름을 비교합니다.

주요 마일스톤 하이라이트

통산 기록 돌파, 수상 내역, 이적·데뷔·은퇴 등 주요 사건을 타임라인 위에 표시합니다.

상대 비교 레이더 차트

선택한 두 선수의 여러 스탯을 레이더 차트로 나란히 비교합니다.

원문 출처 확인

KBO 공식 기록과 Baseball Reference 페이지로 직접 연결됩니다.

03 / DATA & METHODS

데이터와 분석 방법

KBO 공식 기록실
KBO 리그 시즌별 타격·투구 성적 원자료. 강민호·이대호·오승환·김현수 국내 기록.
Baseball Reference
MLB·마이너리그 시즌별 성적. 추신수·오승환·이대호·김현수 미국 기록.
Statcast / Fangraphs
MLB 고급 스탯(wRC+, fWAR, K%, BB%) 참고. 비교 맥락 제공 용도.

포스트시즌 기록은 별도 표기하며 통산 기록에 포함하지 않습니다. 기록 기준: 2024 시즌 종료 기준.

04 / HOW TO USE

어떻게 활용할 수 있는가

야구 팬

좋아하는 선수의 커리어 전체를 한눈에 탐색하고 다른 레전드와 비교합니다.

스포츠 콘텐츠 제작자

선수 비교 콘텐츠 제작 시 정확한 기록과 출처를 빠르게 확인합니다.

야구 데이터 연구자

KBO·MLB를 아우르는 장기 커리어 데이터를 탐색하고 분석의 출발점으로 활용합니다.
