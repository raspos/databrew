databrew 기사 관리

처음 한 번만 연결하세요

이 화면은 GitHub 저장소에 글과 사진을 올려 주는 도구입니다. 접근 토큰을 넣어야만 동작하며, 토큰은 이 브라우저에만 저장되고 서버로 보내지 않습니다.

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → raspos/databrew
  3. Permissions → Repository permissions → Contents: Read and write (다른 권한은 필요 없음)
  4. 만료일은 짧게(예: 90일) 정하고, 생성된 토큰을 아래에 붙여 넣으세요.

연결 후 브라우저가 "비밀번호를 저장할까요?"라고 물으면 저장하세요. 다음부터 이 칸이 자동으로 채워집니다.
