국뽕의 과학 메인 화면 — 53개 지표 카드 탐색기와 국가 비교 모드. 2026-10-15 캡처.

01 / WHY

왜 만들었는가

"한국이 세계 몇 위야?" 하는 질문은 맥락 없이 오가는 경우가 많다. 경제 규모는 상위권이지만 노동시간·불평등·자살률에서는 최하위권이기도 하다. 전체 지표를 한 화면에서 보기 전까지 어느 쪽이 '사실'인지 알기 어렵다.

53개 지표를 국제기구 공식 출처만으로 선별하고, 선택적으로 인용하거나 자의적으로 해석하지 않도록 맥락 설명을 붙였다. '국뽕'이라는 제목은 한국에 대한 과잉 자부심과 과잉 비관 모두를 함께 검토하자는 의미입니다.

데이터 출처: 세계은행, OECD, WIPO, UNDP, IFR(국제로봇연맹), IOC, WHO, ILO, IMF 공식 발표 데이터만 수록. 비교 대상 국가 수는 지표마다 다릅니다.

02 / FEATURES

무엇을 할 수 있는가

53개 지표 탐색

경제·기술·사회·환경·스포츠 카테고리로 필터링해 원하는 지표의 한국 순위와 값을 확인합니다.

국가별 비교

최대 5개국을 선택해 53개 지표 전체에서 나란히 비교합니다. G7·OECD 회원국 기준 필터도 제공합니다.

50년 타임라인

1973년부터 2023년까지 한국이 어떤 지표에서 어떻게 순위가 바뀌었는지 연도별로 확인합니다.

세계지도 시각화

지표별로 세계 지도 위에 각국 순위와 값을 색상으로 표시합니다. D3 Geo·TopoJSON 기반.

순위 퀴즈 (28문항)

28개 지표에서 한국 순위를 맞히는 인터랙티브 퀴즈로 '내가 얼마나 알고 있나'를 확인합니다.

출처 투명 공개

모든 지표에서 국제기구 원문 출처 링크와 최신 데이터 기준 연도를 함께 표시합니다.

03 / DATA & METHODS

데이터와 분석 방법

세계은행
GDP, 무역액, R&D 투자, 인터넷 보급률, 기대수명, 유아사망률 등 거시·사회 지표.
OECD
연평균 노동시간, 소득불평등(지니), 교육비 지출, 노인 빈곤율, 자살률, 삶의 만족도.
WIPO
글로벌 혁신지수(GII), 특허 출원 건수, 상표·디자인 등록.
UNDP
인간개발지수(HDI), 젠더불평등지수(GII), 다차원빈곤지수.
IFR (국제로봇연맹)
제조업 로봇 밀도(근로자 1만 명당 설치 대수).
IOC·FIFA·기타
하계올림픽 메달 순위, FIFA 랭킹, e스포츠 대회 성적.

모든 데이터는 국제기구 공식 발표 원자료만 수록하며, 2차 가공 통계는 사용하지 않습니다. 데이터 기준 연도는 지표마다 다릅니다 (각 지표 상세 화면에서 확인).

04 / HOW TO USE

어떻게 활용할 수 있는가

경제·사회 기자

한국의 특정 지표 순위를 국제 비교 맥락에서 확인하고 공식 출처를 바로 확보합니다.

교육·연구 목적

사회과학·경제학 수업에서 국제 비교 지표를 인터랙티브로 탐색하고 50년 변화를 이해합니다.

일반 독자

퀴즈로 자신이 실제로 한국 순위를 얼마나 정확히 알고 있는지 확인합니다.

06 / TECH STACK

기술 및 제작 방식

Next.js React TypeScript Tailwind CSS 4 Recharts D3 Geo / TopoJSON Python (데이터 파이프라인) Vercel Claude Code
